# 学多多

纯前端、可离线运行的教育 / 学习类 Web 应用。基于 **React 18 + KaTeX** 构建，所有依赖已本地化到 `vendor/`，用浏览器直接打开 `index.html` 即可使用，无需联网、无需构建、无需后端。

> 💡 本项目由 **AI 辅助开发**（基于 WorkBuddy 等 AI 工具完成代码生成、拆分与文档编写）。

## 特性

- **完全离线**：React / ReactDOM / KaTeX 及其字体均已本地化，双击 `index.html`（或 `file://` 打开）即可运行，不依赖任何外网 CDN。
- **数学公式渲染**：内置 KaTeX，支持公式的输入与渲染。
- **数据本地加密**：用户数据写入 `localStorage` 时经加密层透明加密（见 `crypto.js`），降低明文泄露风险。
- **加密备份**：支持用密码导出 / 导入加密备份文件（ChaCha20 + 口令派生密钥）。
- **存储容错**：内置 `storage-shim.js`，当 `localStorage` / `sessionStorage` 不可用时降级为内存存储，避免白屏。

## 功能介绍

应用围绕「题库 → 答题 / 练习 → 错题 / 收藏 → 统计激励」组织，主要功能区如下：

### 题库管理

- **多题型支持**：单选题、多选题、判断题、填空题、解答题五种题型；未识别题型自动按单选 / 填空兜底，保证所有题都能练。
- **富文本题目**：题干与选项支持 Markdown（段落、表格、粗体 / 斜体 / 删除线 / 链接）、代码块，以及 **LaTeX 公式**（`$...$` 行内、`$$...$$` 块级），由 KaTeX 渲染。
- **文件夹层级**：支持多层嵌套文件夹管理题库，题目可在题库间移动 / 复制。
- **导入 / 导出**：
  - 支持从文件或文件夹**拖拽导入**（浏览器原生目录遍历，含嵌套子目录）；
  - 单个题库导出为 JSON；文件夹整体导出为 JSON 并可在导入时重建目录结构；
  - **导出 PDF**：按题型分大题、卷头信息栏、答题横线、分页页码的试卷化 A4 排版，可选是否包含答案与解析，公式正确显示。
- **合并题库**：可把多个题库合并为一个，合并名称优先由 AI 生成（无 API 时回退为名称拼接）。

### 答题与练习

- **答题模式**：逐题作答，实时判分（得分 = 答对题分值之和），即时发放经验并检测升级。
- **练习模式**：针对指定题库 / 错题本 / 收藏夹练习，记录练习进度。
- **错题本**：答错的题自动归集，再次答错会累加错误答案；可一键清空或单独练习。
- **收藏夹**：题目可收藏，支持集中复习。
- 错题本 / 收藏夹带有**「未读」徽标**（微信消息式），显示自上次查看以来的新增数量。

### AI 辅助（需配置模型 / API）

- **智能出题**：粘贴文本即可生成混合题型的练习题，并自动按 LaTeX 规范排版数学公式。
- **解答题批改**：对主观解答题判断正误并给出简要点评。
- **题库命名**：合并题库时由 AI 生成概括性名称。
- 在「模型 / API 设置」中接入自有 API 后启用；不配置则仅离线功能可用。

### 学习激励与统计

- **等级 / 经验**：答题与练习获得经验，累积升级。
- **🔥 登录日历 / 连续打卡**：记录每日登录，支持查看登录日历与「本月进度」统计。
- 侧边栏实时展示等级、经验与连续天数。

### 音乐播放

- 内置本地音频播放器，歌曲存于 IndexedDB（不随普通文本备份混淆），可把音频文件拖拽到音乐面板添加。

### 数据与备份

- **本地加密存储**：所有数据写入 `localStorage` 前经加密层透明加密。
- **加密备份**：一键导出 `.xddbackup` 文件（ChaCha20 + 口令派生密钥），覆盖题库、错题、收藏、文件夹、进度、API 配置、个人信息与本地音乐；导入时输入密码解密恢复。**密码无法找回，请务必牢记。**
- **恢复出厂设置**：侧边栏底部三步确认后清空全部本地数据（含题库、错题、收藏、进度、API 配置与音乐列表），不可撤销。

### 个性化

- **「我的」页面（桌面端）**：个人资料（昵称，左上角显示等级徽标而非自定义头像）、等级 / 🔥、模型 / API 设置、主题切换，以及加密备份与恢复出厂设置入口，整合在同一个桌面页面中。

## 目录结构

### 部署所需文件（整体拷贝即可运行，无需安装依赖、无需构建）

```
xueduoduo/
├── index.html          # 应用外壳：按序加载 vendor 库、crypto.js、styles.css、app.js
├── app.js              # 主程序（React 应用逻辑）
├── styles.css          # 应用样式
├── crypto.js           # 加密层构建产物（已混淆），运行时由 index.html 加载，暴露 window.XDD_CRYPTO / window.XDD_BACKUP
└── vendor/             # 第三方依赖（均已本地化，必须随包部署）
    ├── react.production.min.js
    ├── react-dom.production.min.js
    ├── katex.min.js
    ├── auto-render.min.js
    ├── katex-css.js        # 以 base64 注入 KaTeX 字体样式（<style id="katex-style">），供渲染与导出使用
    └── storage-shim.js     # localStorage/sessionStorage 不可用时的内存降级垫片（须最先加载）
```

> 只要保留上述文件及其相对目录结构，双击 `index.html` 或放到任意静态服务器即可运行。`crypto.js` 是混淆后的构建产物，**运行时必须存在**，但无需改动。

## 本地运行

无需安装任何依赖，任选其一：

1. 双击 `index.html` 用浏览器打开；
2. 或终端启动一个静态服务器后访问，例如：

   ```bash
   # 在项目根目录执行（任选一种）
   python -m http.server 8080
   # 然后浏览器打开 http://localhost:8080
   ```

> 注意：`crypto.js` 须在 `app.js` 之前加载（已在 `index.html` 中排好顺序），否则加密相关功能不可用。

## 加密与数据

- **本地数据加密**：`window.XDD_CRYPTO` 提供对 `localStorage` 的透明加密封装，以及 ChaCha20 原语（`chacha20Xor` / `chacha20Block`、字节与 base64 互转等）。
- **备份加密**：`window.XDD_BACKUP` 提供 `encryptBackup(obj, password)` 与 `decryptBackup(text, password)`。密钥由口令 + 随机盐经多轮（默认 100000）派生得到，密文包含 `format / version / salt / nonce / data` 等字段。
- 所有数据默认仅保存在**当前浏览器本地**，不会上传到任何服务器。

## 注意事项

- **仅支持桌面端**：应用内置设备检测，手机 / 平板（及触屏竖屏设备）打开会被拦截并提示「手机无法使用 / 请使用电脑打开本应用」，暂无移动端适配。
- **导出 / 打印**功能依赖 `vendor/katex-css.js` 注入的 `<style id="katex-style">`（即 `window.KATEX_CSS_TEXT`），改动 KaTeX 相关代码时不要删除该注入。
- `crypto.js` 是混淆后的构建产物，**请勿直接手改**。
- 本项目为纯前端应用，应用数据与备份文件的安全由本地环境和使用者自身负责（尤其是备份密码的保管）。
